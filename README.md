# Bhagwal Kharian | بھگوال کھاریاں

Official Reddit Devvit application for the r/Bhagwalkharian community.

A digital community hub connecting Bhagwal with local maps, Wikipedia history, Discord, and official social media platforms.

## About the Project

Bhagwal Kharian is being developed to bring the Bhagwal community closer through a digital platform on Reddit.

## Built With

- Reddit Devvit
- React
- TypeScript
- Vite
- Hono

## Development

This project is based on the Devvit React Starter.
